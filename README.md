Memory Card Game
A fun and interactive memory card matching game built with React! Test your memory skills by flipping cards to find matching emoji pairs. The game features shuffled cards, move tracking, scoring system, and a congratulatory win message when you complete all matches.

Features
Card Flipping: Click to flip cards and reveal emojis
Matching Logic: Find pairs of matching emojis
Shuffling: Cards are randomly shuffled on game start and reset
Score Tracking: Keep track of matches and moves
Win Condition: Celebration message with final move count
Responsive Design: Built with modern React and CSS
Technologies Used
React (Hooks for state management)
JavaScript (ES6+)
CSS (Styling for card animations and layout)
